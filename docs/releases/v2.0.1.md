**NTFS for Mac 2.0.1 Lotus** fixes NTFS formatting of USB and other removable drives. In 2.0.0 that format failed and left an empty exFAT volume behind.

[**⬇ Download NTFS-for-Mac.dmg**](https://github.com/dovancuongadhp/ntfs-for-mac/releases/download/v2.0.1/NTFS-for-Mac.dmg) · Requires **macOS 26 or later** (Apple silicon or Intel) · [Tiếng Việt bên dưới](#tiếng-việt)

## Fixed

- **NTFS format on a removable drive failed.** Choosing NTFS and confirming the name ended with “Creating the NTFS file system failed. The partition may not be usable; format it again.” Nothing of yours was destroyed: macOS had only created an empty exFAT placeholder, often named NTFS. The formatter never opened the disk, because macOS blocks a direct open of a removable volume even for an administrator. NTFS for Mac now opens the drive through macOS’s permission prompt and formats it with that access. The first time, allow access to removable volumes if macOS asks.
- **A blocked drive now says what to do.** If access is still refused, the message points to System Settings → Privacy & Security → Files & Folders, and asks you to allow NTFS for Mac to access removable volumes.
- **One drive was shown twice.** A disk that also contains an APFS volume appeared as two rows with the same hardware name. macOS creates a virtual disk for that volume, and NTFS for Mac lost track of it when the drive's name contained a space. It is now listed once, with the APFS volume among its partitions.
- **NTFS formatting stopped after the exFAT step.** On a partition diskutil had to retype, formatting ended with “The partition was erased and formatted as exFAT, but NTFS formatting didn't finish (the drive changed).” diskutil reports the new file system a little smaller than the partition. That size change is still the same partition, so NTFS formatting continues and uses the size diskutil reported.
- **A finished NTFS volume still appeared as exFAT.** The NTFS file system was already written, but macOS kept the old label when it could not re-read the whole disk while other partitions stayed in use. NTFS for Mac now mounts the new volume and shows NTFS from that mount.

## Changed

- **The old “Advanced” section explains itself.** It is now “Cluster size and quick format,” with a line under each option. Cluster size is how much space one file takes at minimum; leave it on Automatic unless the drive will hold mostly large files. Quick format stays on; turning it off overwrites the whole partition with zeros and takes a long time. The defaults are the same as 2.0.0.

## Install or update

1. Download `NTFS-for-Mac.dmg` below and drag **NTFS for Mac** into Applications, replacing the old copy.
2. This build is **not notarized by Apple yet**. On first launch, click **Done**, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
3. **New users only:** switch on **NTFS for Mac** under **System Settings → General → Login Items & Extensions → File System Extensions**.

See the [README](https://github.com/dovancuongadhp/ntfs-for-mac#readme) for the full guide and FAQ.

## Known limitations

Volume repair, resizing or adding partitions, editing ACLs, BitLocker drives and EFS-encrypted files are not supported yet.

## Tiếng Việt

**NTFS for Mac 2.0.1 Lotus** sửa lỗi định dạng NTFS trên USB và các ổ rời khác. Ở bản 2.0.0, việc định dạng thất bại và để lại một phân vùng exFAT trống.

### Đã sửa

- **Định dạng NTFS trên ổ rời bị lỗi.** Chọn NTFS và xác nhận tên thì báo “Creating the NTFS file system failed. The partition may not be usable; format it again.” Dữ liệu của bạn không bị phá thêm: macOS mới chỉ tạo một phân vùng exFAT trống, thường đặt tên NTFS. Công cụ định dạng không mở được ổ, vì macOS chặn việc mở trực tiếp ổ rời, kể cả với quản trị viên. NTFS for Mac giờ mở ổ qua hộp thoại quyền của macOS rồi định dạng bằng quyền đó. Lần đầu, hãy cho phép truy cập ổ rời nếu macOS hỏi.
- **Khi ổ vẫn bị chặn, thông báo chỉ chỗ cần bật.** Nếu quyền vẫn bị từ chối, thông báo dẫn tới Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Tệp và thư mục, và bảo bạn cho phép NTFS for Mac truy cập ổ rời.
- **Một ổ bị hiện thành hai dòng.** Ổ nào có thêm volume APFS thì xuất hiện hai lần, cùng tên phần cứng. macOS tạo một đĩa ảo cho volume đó, và NTFS for Mac không nhận ra đĩa ảo thuộc phân vùng nào khi tên ổ có dấu cách. Giờ ổ chỉ hiện một lần, volume APFS nằm trong các phân vùng của nó.
- **Định dạng NTFS dừng sau bước exFAT.** Với phân vùng mà diskutil phải đổi loại, việc định dạng kết thúc bằng “The partition was erased and formatted as exFAT, but NTFS formatting didn't finish (the drive changed).” diskutil báo file system mới nhỏ hơn phân vùng một chút. Đó vẫn là cùng một phân vùng, nên bước NTFS chạy tiếp với đúng dung lượng vừa báo.
- **Ổ đã ghi NTFS xong vẫn hiện exFAT.** File system NTFS đã được ghi, nhưng macOS giữ nhãn cũ khi không đọc lại được cả ổ vì các phân vùng khác vẫn đang dùng. NTFS for Mac giờ gắn volume mới và hiện NTFS theo lần gắn đó.

### Thay đổi

- **Mục trước đây chỉ ghi “Nâng cao” nay nói rõ bên trong là gì.** Dòng đó là “Kích thước cụm và định dạng nhanh”, kèm một câu giải thích cho mỗi mục. Kích thước cụm là chỗ nhỏ nhất một tệp chiếm; hãy để Tự động, trừ khi ổ chủ yếu chứa tệp lớn. Định dạng nhanh vẫn bật; tắt đi thì máy ghi số 0 lên cả phân vùng và mất nhiều thời gian. Mặc định giống bản 2.0.0.

### Cài đặt hoặc cập nhật

1. Tải `NTFS-for-Mac.dmg` bên dưới, kéo **NTFS for Mac** vào Applications và chọn thay thế bản cũ.
2. Bản này **chưa được Apple công chứng**. Lần mở đầu tiên, bấm **Xong**, rồi vào **Cài đặt hệ thống → Quyền riêng tư & Bảo mật** và bấm **Vẫn mở**.
3. **Chỉ với người cài lần đầu:** bật **NTFS for Mac** trong **Cài đặt hệ thống → Cài đặt chung → Mục đăng nhập & tiện ích mở rộng → Tiện ích mở rộng hệ thống tệp**.

Xem [hướng dẫn đầy đủ và câu hỏi thường gặp](https://github.com/dovancuongadhp/ntfs-for-mac/blob/main/README.vi.md).

### Giới hạn hiện tại

Chưa hỗ trợ sửa lỗi ổ, đổi kích thước hay thêm phân vùng, chỉnh phân quyền ACL, ổ BitLocker và tệp mã hoá EFS.
