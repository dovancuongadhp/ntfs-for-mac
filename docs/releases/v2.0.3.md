**NTFS for Mac 2.0.3 Lotus** mounts a drive when you plug it in, and the main window shows the drive list.

[**⬇ Download NTFS-for-Mac.dmg**](https://github.com/dovancuongadhp/ntfs-for-mac/releases/download/v2.0.3/NTFS-for-Mac.dmg) · Requires **macOS 26 or later** (Apple silicon or Intel) · [Tiếng Việt bên dưới](#tiếng-việt)

## Fixed

- **Plugging in a drive no longer says “Unable to invoke task”.** The app started a second mount while macOS was already mounting, and it ran that command as an administrator. The file system extension only starts for the person who is logged in, so every connection failed with that message. NTFS for Mac now waits for the mount already underway, then mounts as the logged-in user.
- **An exFAT partition on the same disk stays exFAT.** Before macOS had identified the partition, it was treated as NTFS and hit the same error.
- **The main window is no longer blank.** In Light Mode the drive list was white on white, because the window was created while the app was still only a menu-bar item.

## Install or update

1. Download `NTFS-for-Mac.dmg` below and drag **NTFS for Mac** into Applications, replacing the old copy. From 2.0.2 onward, Settings can do this for the next release.
2. Eject the NTFS drive and connect it again, so the new file system extension is the one serving it. A drive left mounted from 2.0.2 still uses the old extension.
3. This build is **not notarized by Apple yet**. On first launch, click **Done**, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
4. **New users only:** switch on **NTFS for Mac** under **System Settings → General → Login Items & Extensions → File System Extensions**.

See the [README](https://github.com/dovancuongadhp/ntfs-for-mac#readme) for the full guide and FAQ.

## Known limitations

Volume repair, resizing or adding partitions, editing ACLs, BitLocker drives and EFS-encrypted files are not supported yet.

## Tiếng Việt

**NTFS for Mac 2.0.3 Lotus** gắn được ổ khi cắm vào, và cửa sổ chính hiện danh sách ổ.

### Đã sửa

- **Cắm ổ không còn báo “Unable to invoke task”.** Ứng dụng bắt đầu một lần gắn thứ hai trong lúc macOS đang gắn, và chạy lệnh đó bằng quyền quản trị. Tiện ích hệ thống tệp chỉ khởi động cho người đang đăng nhập, nên mỗi lần cắm đều thất bại với câu đó. NTFS for Mac giờ đợi lần gắn đang diễn ra, rồi gắn bằng tài khoản đang đăng nhập.
- **Phân vùng exFAT trên cùng một ổ vẫn là exFAT.** Trước khi macOS nhận ra phân vùng, nó bị coi là NTFS và gặp cùng lỗi.
- **Cửa sổ chính không còn trắng.** Ở giao diện sáng, danh sách ổ được vẽ màu trắng trên nền trắng, vì cửa sổ được tạo khi ứng dụng vẫn chỉ là mục trên thanh menu.

### Cài đặt hoặc cập nhật

1. Tải `NTFS-for-Mac.dmg` bên dưới, kéo **NTFS for Mac** vào Applications và chọn thay thế bản cũ. Từ 2.0.2, Cài đặt có thể làm việc này cho bản sau.
2. Đẩy ổ NTFS ra rồi cắm lại, để tiện ích mở rộng mới là bản đang phục vụ ổ. Ổ còn gắn từ bản 2.0.2 vẫn dùng tiện ích cũ.
3. Bản này **chưa được Apple công chứng**. Lần mở đầu tiên, bấm **Xong**, rồi vào **Cài đặt hệ thống → Quyền riêng tư & Bảo mật** và bấm **Vẫn mở**.
4. **Chỉ với người cài lần đầu:** bật **NTFS for Mac** trong **Cài đặt hệ thống → Cài đặt chung → Mục đăng nhập & tiện ích mở rộng → Tiện ích mở rộng hệ thống tệp**.

Xem [hướng dẫn đầy đủ và câu hỏi thường gặp](https://github.com/dovancuongadhp/ntfs-for-mac/blob/main/README.vi.md).

### Giới hạn hiện tại

Chưa hỗ trợ sửa lỗi ổ, đổi kích thước hay thêm phân vùng, chỉnh phân quyền ACL, ổ BitLocker và tệp mã hoá EFS.
